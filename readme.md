# Healthcare Recommendation System
A frontend-based healthcare recommendation web application that predicts possible diseases from user-entered symptoms and provides treatment suggestions along with multilingual educational video recommendations.

The project is built entirely using frontend technologies without any backend or external API integration.

## Author
Saksham Bhargava

## Features
- Symptom-based disease prediction
- Treatment recommendation
- English & Hindi medical videos
- Dynamic disease matching algorithm
- Frontend-only architecture
- LocalStorage support

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How It Works
1. User enters personal details and symptoms.
2. The system compares symptoms with a predefined disease dataset.
3. The best matching disease is identified using a rule-based matching algorithm.
4. Recommended treatment and related educational videos are displayed dynamically.
